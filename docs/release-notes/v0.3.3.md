# HMTrans v0.3.3（macOS · HarmonyOS）

本次更新解决一个影响日常使用的问题：**切换 Wi-Fi 后，原来已经配对过的设备会被要求重新配对**。

配对关系本来就应该绑定设备，而不是绑定网络。v0.3.3 把「配对」和「在线状态」彻底分开：换 Wi-Fi、短暂断网、对方暂时没回应，都不再清除已保存的配对关系；网络恢复后双端会主动找回已配对设备并自动恢复连接，不需要重新输入六位配对码。

## 配对关系不再被网络问题清除

- 切换 Wi-Fi、信号波动或对端暂时无响应时，不再删除本机保存的配对关系。
- 配对关系现在只有两个清除入口：用户在设备上主动「忘记设备」，或对端发来带签名的解除配对请求。
- 点「重新连接」不再触发倒计时删除信任；未收到回应时只提示配对关系保持不变、可稍后重试。

## 网络恢复后自动重新连接

- 网络就绪后，双端会向每台已配对设备的已知地址主动发送定向发现报文，不再被动等待下一个广播周期。
- 为每台已配对设备维护最近的已知地址列表，换网段拿到新 IP 后也能被找回。
- 设备卡片新增「正在重新连接…」状态，替换原先容易误解的「点击重新连接」。

## 设备身份不再依赖 IP

- 设备去重与身份判断只使用稳定设备 ID，IP 仅作为传输目标使用。
- 避免 IP 被 DHCP 重新分配后，两台不同设备被误合并，或已配对设备被当成陌生设备。

## 平台与兼容

- macOS 版适用于 macOS 26 及以上，安装包为 ad-hoc 本地签名，未经 Developer ID 签名或公证。
- HarmonyOS 版已改用新版 HarmonyOS SDK 构建，可覆盖 HarmonyOS 7 设备；仍保持对 HarmonyOS 6.1 及以上设备的安装兼容。

## 安装说明

下载 `HMTrans.dmg`，打开后将 `HMTrans.app` 拖入“应用程序”。首次打开若被系统拦截，可右键应用选择“打开”，或在“隐私与安全性”中允许。

HarmonyOS 版请在华为应用市场搜索“HM互传”获取；上架版本以应用市场显示为准。
