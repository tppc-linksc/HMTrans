# HMTrans v0.3.2（macOS）

本次更新收口 Mac 菜单栏常驻入口与图标显示，并同步近期稳定性和 HarmonyOS 设备适配源码。文件互传和本地加密投屏仍保持局域网直连，不增加云端或账号。

## Mac 安装包更新

- 菜单栏常驻入口改用单色莫比乌斯 Logo，自动适配系统明暗模式，不再显示方形背景、光效或多余缩略图。
- 点击菜单栏图标直接打开任务中心；移除容易意外消失的悬停面板及不稳定的菜单栏拖放入口。
- 应用、Dock 与安装镜像继续使用新版莫比乌斯图标。

## 同期源码修复

- HarmonyOS 手机与阔折叠设备使用更紧凑的连接页布局；设备较多时显示图标网格，并可点开详情执行连接、投屏或忘记设备。
- 历史页增加多选、分组选择、全选与批量删除，改善窄屏操作效率。
- 接收目录会根据设备能力选择公共下载目录或应用内兜底目录，并在设置中明确显示实际位置。
- 修复系统录屏被停止后投屏状态可能仍停留在“投屏中”、Mac 画面冻结的问题。
- 为短连接关闭增加尾包宽限，避免配对、解绑或校验回执在连接关闭时被误判为失败。

HarmonyOS 应用市场公开版仍为 `v0.3.0`。上述 HarmonyOS 开发版改动不包含在本次 Mac DMG 中，也未作为应用市场更新发布；本 Release 不提供 HAP。

## 安装说明

下载 `HMTrans.dmg`，打开后将 `HMTrans.app` 拖入“应用程序”。要求 macOS 26 或更高版本。当前安装包仅为 ad-hoc 签名，未经 Apple Developer ID 签名或公证；首次打开若被系统拦截，可右键应用选择“打开”，或在“隐私与安全性”中允许。
