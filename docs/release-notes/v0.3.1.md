# HMTrans v0.3.1（macOS）

本次 Mac 更新换上新的莫比乌斯环标志，并收录 `v0.3.0` 之后的连接与传输稳定性修复。文件互传和本地加密投屏仍保持局域网直连，不增加云端或账号。

## Mac 安装包更新

- 更新应用、Dock 和安装镜像图标；右上角菜单栏常驻入口改为透明背景的莫比乌斯环 Logo，而非带白底的方形图标。
- 改善 Wi-Fi 切换后的网络状态清理和自动重建，减少旧网络信息残留。
- 修复断线续传后已有实际字节进度、任务仍显示“准备中”或“等待重连”的问题，并让传输错误提示更明确。

## 同期源码修复

- HarmonyOS 端修复历史列表纵向滚动和窄屏筛选按钮布局，并改善文件传输重连及诊断记录。
- 仓库开发版增加 HarmonyOS 手机、阔折叠设备支持，投屏编码画布按当前设备屏幕比例生成；已在 Pura X View 上完成调试包安装。
- 官网与文档同步更新图标及版本状态。

HarmonyOS 应用市场公开版仍为 `v0.3.0`。上述 HarmonyOS 开发版改动不包含在本次 Mac DMG 中，也未作为应用市场更新发布；本 Release 不提供 HAP。

## 安装说明

下载 `HMTrans.dmg`，打开后将 `HMTrans.app` 拖入“应用程序”。要求 macOS 26 或更高版本。当前安装包仅为 ad-hoc 签名，未经 Apple Developer ID 签名或公证；首次打开若被系统拦截，可右键应用选择“打开”，或在“隐私与安全性”中允许。
